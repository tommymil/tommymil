# Code Builder — poznajemy Agenta
Subject: Minecraft Education
Level: Poziom 1 — 8-10 lat, bloki
Czas: 95 min
Tags: Code Builder, MakeCode, Agent, Pierwszy program
Opis: Najważniejsza lekcja pierwszego miesiąca. Dzieci otwierają Code Builder, poznają Agenta i wydają mu pierwsze komendy z bloczków.
Cel: Dziecko otwiera Code Builder, buduje program z bloczków uruchamiany komendą z czatu i steruje Agentem, rozumiejąc, że Agent porusza się względem siebie, a nie względem gracza.

### Po zajęciach dziecko potrafi
- otworzyć Code Builder i utworzyć nowy projekt MakeCode w trybie bloków
- zbudować program uruchamiany komendą wpisaną na czacie
- przywołać Agenta i kazać mu iść oraz skręcić
- wyjaśnić, że „w przód” znaczy w przód Agenta, a nie gracza

### Przygotuj przed zajęciami
- gotowe demo: Agent budujący ścieżkę i mur na komendę
- **sprawdzone, że Code Builder otwiera się w Twojej wersji gry** — klawisz C albo ikona w menu
- światy dzieci z lekcji 2
- przygotowana informacja, czy interfejs MakeCode jest u dzieci po polsku, czy po angielsku

### Zadanie domowe
- wymyśl trzy komendy, które chciałbyś wydać Agentowi, i zapisz je zwykłymi zdaniami

## [intro] Powitanie i demo Agenta (8 min)

### Co robić teraz
- [mów] Cześć! Dziś ten dzień. Poznajecie Agenta.
- **Sprawdzenie obecności:** odczytaj listę uczestników i zaznacz obecnych.
- **DEMO:** przywołaj Agenta na swoim ekranie. Pokaż go z bliska — to mały robot, który stoi obok gracza.
- Wpisz komendę na czacie. Agent idzie i stawia ścieżkę z bloków. Potem druga komenda: buduje mur.
- [mów] Pamiętacie ścianę z zeszłego tygodnia? Sto bloków, kilka minut, u połowy z was wyszła krzywa. Patrzcie.
- Uruchom program budujący identyczną ścianę. Odlicz na głos sekundy.
- [mów] I ani jeden blok nie jest krzywo. Zawsze. Za każdym razem.
- [mów] Agent robi dokładnie to, co mu każecie. Ani mniej, ani więcej. Dziś nauczycie się mu to mówić.

### Wskazówki
- [tempo] To jest wypłata za dwa tygodnie ręcznego budowania. Zrób z tego widowisko — porównaj z ich własnymi czasami z zeszłego tygodnia.
- [podpowiedź] Zdanie „Agent robi dokładnie to, co mu każesz, ani mniej, ani więcej” wraca przez cały kurs przy każdym błędzie. Powiedz je dziś pierwszy raz.

## [review] Wracamy do świata i przypominamy współrzędne (5 min)

### Co robić teraz
- Wszyscy otwierają świat z lekcji 2. Poczekaj na potwierdzenie od każdego dziecka.
- Kto nie ma świata, zakłada nowy: Kreatywny, płaski.
- Szybka powtórka: co oznacza Y? Który przycisk stawia blok? Ile bloków ma ściana dwadzieścia na pięć?
- Poproś, żeby wszyscy odlecieli na **puste miejsce** obok swoich budowli i tam wylądowali.
- [mów] Zostawcie sobie dużo wolnej przestrzeni. Agent będzie chodził i stawiał bloki, a na początku nie zawsze tam, gdzie chcecie.

### Wskazówki
- [podpowiedź] Praca na pustym terenie, z dala od gotowych budowli, oszczędza wiele łez na pierwszej lekcji z Agentem.
- [gdy nie zdążysz] Sam start świata i przelot na puste miejsce.

## [concept] Otwieramy Code Builder (14 min)

### Co robić teraz
- [mów] W Minecrafcie Education jest wbudowany edytor kodu. Otwiera się jednym klawiszem.
- Krok 1: naciśnijcie klawisz **C**. Otwiera się okno Code Builder. **Czekaj, aż każde dziecko potwierdzi na czacie literą C.**
- Krok 2: w oknie wybierzcie **MakeCode**. To edytor, w którym będziemy pracować przez cały kurs.
- Krok 3: kliknijcie Nowy projekt i nadajcie mu nazwę. Wybierzcie widok **bloków**, nie tekstu.
- [mów] Popatrzcie na ekran. Po lewej są kategorie bloczków, na środku miejsce na program, a w rogu widać kawałek Minecrafta.
- [mów] Kto z was widział już Scratcha? To wygląda podobnie i to nie przypadek — to ten sam pomysł.
- Krok 4: obejrzyjcie kategorie: Player, Blocks, Agent, Loops, Logic, Variables. Nie omawiaj ich szczegółowo, to mapa, nie wykład.
- Krok 5: pokaż, jak wrócić do gry bez zamykania kodu — klawisz Escape albo ikona. Program zostaje.
- [mów] Będziecie przełączać się między kodem a grą kilkadziesiąt razy na każdej lekcji. Poćwiczcie to teraz: kod, gra, kod, gra.

### Wskazówki
- [błąd] Code Builder nie otwiera się klawiszem C. W niektórych wersjach i układach klawiatury jest inaczej — sprawdź to **przed** zajęciami i miej przygotowaną drogę przez menu.
- [błąd] Okno Code Builder jest maleńkie albo nie mieści się na ekranie. Da się je powiększyć — pokaż jak. Na małych laptopach to realny problem.
- [błąd] Dziecko wybrało widok tekstowy zamiast bloków. Przełącznik jest na górze ekranu.
- [błąd] Interfejs MakeCode jest po angielsku, a dziecko nie zna angielskiego. Podawaj nazwy bloczków po polsku i po angielsku, zawsze obie. Na tym poziomie dzieci rozpoznają bloczki po kolorze i kształcie szybciej niż po nazwie.
- [podpowiedź] Przełączanie kod-gra jest mechaniczną umiejętnością, którą trzeba wyćwiczyć osobno. Poświęć na to minutę, a oszczędzisz dziesięć.
- [tempo] Jeśli po czternastu minutach ktoś nie ma otwartego Code Buildera, przydziel mu opiekuna z grupy i idź dalej.

### Materiały
- [link] Minecraft Education — Code Builder | https://education.minecraft.net/

## [guided] Pierwszy program i pierwsza komenda (18 min)

### Co robić teraz
- Budujemy razem. Po każdym kroku czekasz na kciuki od wszystkich.
- Krok 1: z kategorii **Player** weźcie bloczek „on chat command”, czyli „po komendzie na czacie”. Przeciągnijcie go na środek. **Czekaj na kciuki.**
- Krok 2: w białym polu wpiszcie słowo **start**. To będzie nazwa waszej komendy.
- [mów] To jest wasz uruchamiacz. W Scratchu byłaby to zielona flaga. Tutaj program rusza, gdy wpiszecie w grze na czacie ukośnik i słowo start.
- Krok 3: z kategorii **Agent** weźcie bloczek „agent teleport to player”, czyli „przenieś Agenta do gracza”. Włóżcie go do środka.
- Krok 4: wróćcie do gry. Otwórzcie czat klawiszem T albo ukośnikiem i wpiszcie komendę start.
- Krok 5: Agent pojawia się obok was. **Czekaj na kciuki od wszystkich.**
- [mów] To jest wasz pierwszy program. Cztery kliknięcia i robot stoi obok was.
- Krok 6: dołóżcie do programu bloczek „agent move forward 1”, czyli „Agent idź w przód o 1”.
- Krok 7: wróćcie do gry, wpiszcie komendę. Agent robi jeden krok.
- Krok 8: zmieńcie liczbę 1 na 5. Uruchomcie ponownie. Agent idzie pięć kroków.
- [mów] Zauważcie, że przy każdym uruchomieniu Agent przenosi się najpierw do was, a dopiero potem idzie. Dlatego zaczyna zawsze w tym samym miejscu — przy was.

### Wskazówki
- [podpowiedź] Rozpoczynanie każdego programu od przeniesienia Agenta do gracza to nawyk, który warto wyrobić od pierwszej lekcji. Bez tego Agent startuje z miejsca, w którym skończył poprzednio, i nic się nie zgadza.
- [błąd] Komenda nie działa, bo dziecko wpisało ją bez ukośnika albo z literówką. Nazwy komend są dokładne.
- [błąd] Komenda nie działa, bo dziecko nie zapisało zmian w kodzie. W MakeCode zmiany zwykle działają od razu, ale przy problemach warto zamknąć i otworzyć Code Builder.
- [błąd] Agent nie pojawia się. Sprawdźcie, czy w programie faktycznie jest bloczek przeniesienia i czy jest **w środku** bloczka komendy, a nie obok niego.
- [błąd] Dziecko wpisało polską nazwę komendy z ogonkami. Nazwy komend piszcie bez polskich znaków — to nazwa techniczna, nie tekst.
- [dla szybszych] Niech utworzą drugą komendę o innej nazwie i sprawdzą, że oba programy działają niezależnie.
- [gdy nie zdążysz] Samo przeniesienie Agenta i jeden krok w przód. Reszta po przerwie.

### Materiały
- [kod] Pierwszy program — Agent przychodzi | makecode:
  ```
  on chat command "start"
    agent teleport to player
    agent move forward 1
  ```

## [break] Przerwa (5 min)

### Co robić teraz
- 5 minut przerwy. Dzieci wstają od ekranów, piją wodę.
- Poproś, żeby nie zamykały gry ani Code Buildera.
- Zapowiedź: „Po przerwie Agent nauczy się skręcać. I odkryjecie pułapkę, w którą wpada każdy — łącznie ze mną.”

### Wskazówki
- [tempo] Zapowiedź pułapki działa lepiej niż zapowiedź nowego bloczka. Dzieci wracają ciekawe.

## [concept] Skręcanie i pułapka „w przód” (13 min)

### Co robić teraz
- [mów] Agent umie iść prosto. Teraz nauczy się skręcać — i tu zaczyna się najciekawsza część.
- Krok 1: dołóżcie do programu bloczek „agent turn left”, czyli „Agent skręć w lewo”, a pod nim znowu „agent move forward 3”.
- Krok 2: uruchomcie. Agent idzie, skręca, idzie dalej w bok.
- [mów] A teraz pytanie. Stańcie tak, żeby patrzeć na Agenta **z przodu**, twarzą w twarz. Uruchomcie program. W którą stronę pójdzie?
- Niech spróbują. Agent idzie w swoją stronę, nie w waszą.
- [mów] I to jest najważniejsza rzecz dzisiejszej lekcji. Kiedy mówicie „w przód”, Agent rozumie **swój przód**, a nie wasz. Zawsze.
- [mów] To jest jak z kolegą, którego prowadzicie przez telefon. Mówicie „skręć w lewo” — ale w jego lewo, nie w wasze.
- Krok 3: ćwiczenie. Ustawcie Agenta i spróbujcie przewidzieć, gdzie skończy, **zanim** uruchomicie program. Wpiszcie przewidywanie na czat, potem uruchomcie i sprawdźcie.
- Krok 4: powtórzcie trzy razy, za każdym razem obracając się w inną stronę.
- [mów] Dobra wiadomość: skoro Agent zawsze zaczyna od przeniesienia do was, to jego przód jest zawsze taki jak wasz w chwili startu. Ustawcie się, jak chcecie, i uruchamiajcie.

### Wskazówki
- [podpowiedź] To pojęcie — ruch względny — jest najtrudniejszą rzeczą w całym pierwszym semestrze tej ścieżki i wraca do końca kursu. Porównanie z prowadzeniem kogoś przez telefon działa najlepiej.
- [błąd] Dziecko obraca się w grze i nie rozumie, dlaczego budowla wychodzi w innym miejscu. To dokładnie ten temat. Zaproponuj regułę: przed każdym uruchomieniem stań tak samo.
- [błąd] Agent skręca w drugą stronę, niż dziecko myślało. Poproś, żeby stanęło za Agentem, patrząc w tę samą stronę co on — wtedy lewo i prawo się zgadzają.
- [błąd] Agent wszedł w ścianę budowli i utknął. Agent nie niszczy bloków, jeśli mu tego nie kazano — po prostu się zatrzymuje.
- [dla szybszych] Niech zbudują program, w którym Agent obchodzi kwadrat, i sprawdzą, czy wraca dokładnie tam, gdzie zaczął.
- [gdy nie zdążysz] Sam bloczek skręcania i jedno ćwiczenie z przewidywaniem.

### Materiały
- [kod] Agent idzie i skręca | makecode:
  ```
  on chat command "start"
    agent teleport to player
    agent move forward 3
    agent turn left
    agent move forward 3
  ```

## [guided] Agent obchodzi kwadrat (14 min)

### Co robić teraz
- [mów] Zbudujemy program, w którym Agent obejdzie kwadrat i wróci dokładnie tam, skąd wyszedł.
- Krok 1: zastanówcie się razem, ile razy trzeba iść i ile razy skręcić. Zbierz odpowiedzi z czatu.
- Odpowiedź: cztery razy iść, cztery razy skręcić.
- Krok 2: zbudujcie program: przenieś Agenta do gracza, a potem cztery razy powtórzone „idź w przód o 4” i „skręć w prawo”.
- [mów] Osiem bloczków. Zapamiętajcie tę liczbę — za dwa tygodnie zrobicie to samo trzema.
- Krok 3: uruchomcie. Agent obchodzi kwadrat i wraca. **Czekaj na kciuki.**
- Krok 4: sprawdźcie, czy naprawdę wrócił na to samo miejsce. Zapamiętajcie, gdzie stał na starcie.
- Krok 5: zmieńcie kwadrat na prostokąt: dwa boki po 6 i dwa po 3. Uwaga — kolejność bloczków ma teraz znaczenie.
- Krok 6: dla chętnych: zróbcie trójkąt. Ile stopni ma skręcić Agent? Podpowiedz, że bloczek skręcania obraca o 90 stopni i trójkąta się nim nie da — to dobre odkrycie.

### Wskazówki
- [podpowiedź] Uwaga „osiem bloczków, za dwa tygodnie trzy” jest przygotowaniem pod pętlę z lekcji 5. Powtarzaj ją przy każdej powtarzającej się sekwencji.
- [błąd] Agent nie wraca na start, bo dziecko dało trzy skręty zamiast czterech albo różne długości boków.
- [błąd] Prostokąt wychodzi krzywy, bo dziecko pomyliło kolejność długich i krótkich boków.
- [błąd] Agent zaczyna w innym miejscu przy każdym uruchomieniu, bo brakuje przeniesienia do gracza na początku.
- [błąd] Dziecko próbuje zrobić trójkąt i się frustruje. Powiedz wprost, że tym bloczkiem się nie da, i pochwal za próbę — to poprawne odkrycie ograniczenia narzędzia.
- [dla szybszych] Niech zbudują spiralę: każdy kolejny bok o jeden dłuższy. Wymaga ośmiu par bloczków i jest świetnym argumentem za pętlą.
- [gdy nie zdążysz] Sam kwadrat. Prostokąt zostaje na lekcję 6.

### Materiały
- [kod] Agent obchodzi kwadrat | makecode:
  ```
  on chat command "kwadrat"
    agent teleport to player
    agent move forward 4
    agent turn right
    agent move forward 4
    agent turn right
    agent move forward 4
    agent turn right
    agent move forward 4
    agent turn right
  ```

## [challenge] Twoja trasa dla Agenta (8 min)

### Co robić teraz
- Zadanie samodzielne: zaprogramuj Agentowi trasę własnego pomysłu.
- Najpierw narysuj ją na kartce strzałkami: prosto, prosto, w lewo, prosto.
- Potem zamień strzałki na bloczki.
- Uruchom i sprawdź, czy Agent poszedł tam, gdzie chciałeś.
- Kto skończy, wpisuje na czat, ile bloczków użył.

### Wskazówki
- [tempo] Rysowanie trasy strzałkami przed budowaniem programu jest tu istotą zadania. To pierwszy raz, gdy dziecko planuje program przed napisaniem.
- [dla szybszych] Niech zaprogramują trasę, która wygląda jak litera ich imienia, przechodząc przez nią Agentem.
- [gdy nie zdążysz] Trasa z trzech ruchów wystarczy.
- [błąd] Trasa na kartce nie zgadza się z tym, co robi Agent — prawie zawsze przez pomylenie lewo-prawo względem Agenta. Poproś, żeby dziecko stanęło za Agentem.

## [challenge] Pokaz i wyjście ze świata (5 min)

### Co robić teraz
- Przypomnij o wyjściu przez menu, nie przez zamknięcie okna.
- „Scena dla każdego”: po kolei, po imieniu, każde dziecko udostępnia ekran, uruchamia swoją komendę i pokazuje trasę Agenta.
- Poproś, żeby powiedziało, ile bloczków ma jego program.
- Brawa po każdym pokazie.

### Wskazówki
- [podpowiedź] Zbieranie liczby bloczków od wszystkich dzieci daje materiał do porównania z lekcją 5, gdzie ta liczba spadnie kilkukrotnie.
- [błąd] Program nie działa na pokazie, bo dziecko stoi inaczej niż przy testowaniu. Dobra okazja, żeby jeszcze raz przypomnieć o ruchu względnym.

## [summary] Podsumowanie (5 min)

### Co robić teraz
- Zbierz grupę i zapytaj: jakim klawiszem otwiera się Code Builder? Jak uruchamia się program? Czyj przód ma na myśli Agent, gdy mówi „w przód”?
- [mów] Dzisiaj przestaliście budować i zaczęliście programować. Agent robi dokładnie to, co mu każecie — nic więcej i nic mniej.
- [mów] Na razie tylko chodzi. Za tydzień zacznie stawiać bloki i wtedy naprawdę zacznie się budowanie.
- Zajawka: „Na następnych zajęciach Agent dostanie do ręki bloki. Zbudujecie ścieżkę, po której będziecie mogli przejść.”
- Przypomnij zadanie domowe: trzy komendy zapisane zwykłymi zdaniami.

### Wskazówki
- [błąd] Code Builder nie otwiera się klawiszem C — sprawdź drogę przez menu przed zajęciami.
- [błąd] Komenda nie działa — literówka w nazwie albo brak ukośnika przy wpisywaniu.
- [błąd] Agent startuje z przypadkowego miejsca — brak przeniesienia do gracza na początku programu.
- [błąd] Agent idzie w złą stronę — „w przód” to przód Agenta, nie gracza.
- [błąd] Bloczek leży obok bloczka komendy zamiast w jego środku — program się nie wykonuje.
